Making Roblox games with Claude Code

A short set-up guide for a teenager starting out, and the adult helping them. It gets Claude Code talking to Roblox Studio, then says how to work so the first games actually get finished.

Written 21 November 2026 · the steps come from Roblox's and Rojo's own pages (linked at the end) and were not run while writing this, so follow the official page if a menu name differs

Before anything else: whose account. Claude's terms require the account holder to be 18 or over. For anyone younger, the Claude account belongs to a parent or guardian, who supervises its use.

1. The simple set-up

Roblox Studio can connect to Claude Code directly. No extra tools are needed to begin.

  1. Install Roblox Studio. It is free. Sign in with the Roblox account the games will be made on.
  2. Install Claude Code on the same computer and sign in.
  3. Connect them. In Studio, turn on Enable Studio as MCP server. Then open Assistant Settings → MCP Servers and use quick connect, which lists Claude Code. A green indicator shows when it is connected.
  4. Open a place in Studio, start Claude Code, and ask for something small.
Good first asks
  • "Make a red part that resets the player when they touch it."
  • "Add a coin that gives 10 points and disappears, then comes back after 5 seconds."
  • "Make a door that opens when the player walks up to it."
Roblox's own warning. A connected client can read and change whatever place is open in Studio. Connect it only to your own projects, and only to tools you trust.

2. How to work so games get finished

  • Start tiny. An obstacle course with five stages beats a half-built open world. Finish it, publish it, then make the next one bigger.
  • One change at a time. Ask for one thing, play-test it in Studio, then ask for the next.
  • Say exactly what happened. "When I touch the coin nothing happens and the Output window says 'attempt to index nil'" gets a fix. "It's broken" gets a guess.
  • Ask Claude to explain what it wrote. Roblox games are written in a language called Luau. Reading the explanations is the fastest way to learn it.
  • Say what "done" looks like. "Done is: I can jump on all five platforms and reach the flag."
  • Keep a list of ideas somewhere else. New ideas arrive faster than games get built. Write them down and stay on the game in hand.

3. The step up: the game as files

Once two or three small games are done, the next step is to keep a game as ordinary files on the computer. Claude can then read and change the whole project at once, and Git can save every version. The tool for this is Rojo, installed through a small tool manager called Rokit.

  1. Install Rokit (its page has a one-line installer for Windows and for Mac).
  2. Add Rojo: 
    rokit add rojo-rbx/rojo
rokit install
  3. Install Rojo's Studio half: 
    rojo plugin install
  4. Make a project and start syncing it into Studio: 
    rojo init my-game
cd my-game
rojo serve
    Then connect from the Rojo plugin inside Studio.

Leave this until the simple set-up feels easy. It is how experienced Roblox developers work, and it is not needed for a first game.

4. Is Roblox a good place to start?

It is a real choice, for three reasons: the audience is already there, publishing is one button, and Roblox pays creators whose games are played.

Be honest about the odds: most Roblox games earn little or nothing. Treat it as the best way to learn to make and ship real games in front of real players. Anything it earns is a bonus.

5. Publishing and safety

  • Publishing a game needs a Roblox account. Roblox has its own age rules and parental controls, set on the account.
  • Earning money on Roblox has its own age and identity requirements. Check Roblox's current rules before planning around it.
  • Never put passwords, real names or addresses into a game, a script or a chat with an AI.
